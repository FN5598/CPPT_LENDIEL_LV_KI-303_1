# Звіт до лабораторної роботи № 2

## Тема і варіант

- Предметна область: лікарські засоби.
- Номер варіанта: 11.
- Операційна система: macOS, Apple Silicon (arm64).

## Реалізація

Програма розміщена в `src/main/java/ua/lpnu/lendiel/vitalii/lab02/`.
Вхідні дані повторно використовуються з `src/main/resources/lab01/Data.csv`.

Порівняно з лабораторною роботою № 1, обробку одного CSV-рядка винесено до класу `MedicineInformation`. Його фабричний метод `fromCsv(...)` виконує розбір і перевірку даних. Підсумкові значення зберігаються у записі `MedicineInformationSummary`.

Основна програма обробляє рядки окремо, зберігає коректні записи, накопичує помилки з номерами рядків і розраховує статистику лише для коректних даних.

## Збірка і запуск

```bash
./mvnw clean test
./mvnw package
java -cp target/classes ua.lpnu.lendiel.vitalii.lab02.Lab02Application
```
